## Marca e Uso do Nome

O código-fonte deste projeto é disponibilizado sob a licença Apache 2.0.
No entanto, o nome **Recadinho do Céu**, os logotipos e a identidade visual associada **não** estão cobertos pela concessão da licença de código aberto.

Se você fizer um fork ou redistribuir este software (comercialmente ou não), é necessário alterar a marca, o nome e a identidade visual para evitar confusão no mercado.
